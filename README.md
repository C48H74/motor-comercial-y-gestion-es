# motor-comercial-y-gestion-es

Skill de agente para motor comercial B2B y entrega de proyectos: oferta y precio, metodologías de venta (SPIN, MEDDPICC, JOLT, Challenger), outbound, motor de 12 pasos con diagnóstico y entrega de proyectos (PMBOK 7, valor ganado, riesgo, informes).

- Traducción al español. Versión principal en inglés: `commercial-engine-and-delivery`.
- Empieza por `SKILL.md` (enrutador). Carga un módulo de `references/` y una plantilla de `templates/`.
- Los límites conocidos están declarados en `SKILL.md`.
- Validación: `node scripts/validar_skill.mjs .` y `node scripts/validar_yaml.mjs .` (Node.js; la verificación YAML necesita el paquete `yaml`).
